# 수수료 원장 — 데이터 형식과 갱신 순서

대시보드 탭의 '수수료 원장' 묶음(쪽 6개, 앱메모에 xcheck 가 있으면 7개, 약정 연결이 있으면 '펀드별 약정·입금' 1개 더) = 외화 수수료 입금 원장을 읽기 좋게 나눈 화면.
입금마다 관련 LP·약정금액·수수료율·약정내역 수수료(2026-11-18, 사용자 요청: 연도별 펀드·입금이 어떤 LP·약정·율·수수료인지 모든 쪽에서)는
**대시보드 엑셀(dash.json)의 「약정내역(2022~현재)」(표 cm)·「약정내역(2010~2021)」(표 hi)** 값으로 채운다 — 엑셀을 고치면 다시 반영할 때 따라 바뀐다.
원장 원본은 claude.ai Project 'Back Office 업무연동'의 문서 `claude/외화수수료_원장_2017-2026.csv`
(대화 '수수료 내역 증빙 자료'에서 부가세 영세율 신고자료·회계부 영세율 총괄표·입금결의서·송금명세·인보이스를 대조해 만든 것).
화면에 덧붙이는 설명(기관명·금액이 든 것)은 Project 문서 `claude/외화수수료_원장_앱메모.json` — 공개 저장소 코드에 두지 않는다.
데이터는 암호문 `fees.enc.json` 하나(미팅노트와 같은 비밀번호·salt). 평문(CSV·메모·fees.json)은 스크래치패드에만.

## 갱신 순서 ("수수료 원장 앱에 반영해줘")
1. Project 문서 두 개를 스크래치패드로 받는다(`project_read`; 결과가 글자로 오면 그대로 파일에 쓰지 말고 세션 기록에서 원문을 꺼내 저장 — 숫자 한 자도 바뀌면 안 됨).
2. `node scripts/vault.mjs decrypt dash.enc.json <SP>/dash.json` (약정내역 값) → `python3 scripts/fees_build.py <SP>/외화수수료_원장_2017-2026.csv <SP>/fees.json --notes <SP>/외화수수료_원장_앱메모.json --dash <SP>/dash.json`
   — NO 연속·날짜 형식·신고기간 ↔ 날짜·통화·외화 × 환율 = 원화(±2원)를 확인하고 어긋나면 멈춘다. 출력의 건수·원화 합계·'규칙 밖' 운용사를 본다
   (규칙 밖 이름이 운용사로 묶여야 하면 `GP_RULES` 에 더한다 — 일반 GP·거래처 이름만). '약정 연결 N/529건'·'대시보드에서 못 찾은 행' 줄도 본다
   (못 찾은 행 = 엑셀에서 펀드 약칭·기관 표기가 바뀐 것 — CSV '약정 연결' 칸을 새 표기로 고치거나 CSV 값 그대로 둔다).
3. `node scripts/vault.mjs encrypt <SP>/fees.json fees.enc.json --salt-from data.enc.json`
4. `git status` 로 fees.enc.json(과 고친 코드)만 → 커밋(`fees: 수수료 원장 MM/DD 기준`, 펀드명·금액 쓰지 말 것) → push. 평문 삭제.
- 대시보드 엑셀(dash.enc.json)을 매일 다시 뽑아도 이 묶음은 그대로다(앱이 두 파일을 따로 열어 붙인다).
- **대시보드 엑셀만 바뀌었을 때(약정내역 금액·율·수수료 반영)**: Project 문서 없이 지금 fees.enc.json 으로 다시 만든다 —
  `node scripts/vault.mjs decrypt fees.enc.json <SP>/fees_prev.json` → `python3 scripts/fees_build.py --from <SP>/fees_prev.json <SP>/fees.json --dash <SP>/dash.json`
  → 암호화·커밋(`fees: 약정 연결 MM/DD 대시보드 기준`). fees.json 의 `src`(원장 행·앱메모)를 그대로 다시 쓴다(원장 글자·숫자 그대로).

- 분류(화면용 칸): 중개·Custody·상임대리인 = 중개·수탁·대리인 / 정기수수료 그룹이 있거나 Monitoring·Maintenance·Admin·Trailer·Retainer 등 = 관리·모니터링 /
  번역비·리서치·행사 = 용역·기타 / '미확인' 구분 = 미확인 / 그 밖 = 판매 (PA 등). 운용사 = 펀드·내용에 가장 앞에 나온 이름(`GP_RULES`), 없으면 송금인.
- 원장 글자·숫자는 고치지 않는다(화면용 칸은 분류·운용사 둘뿐). 원화는 원장 '원화금액(결의금액)' — 회사 시스템 결의금액 기준.
- 형식(kind "fees"): `{kind, v, generatedAt, source, asof, range[첫, 끝], n, krw, sheets[]}` — sheets 는 dash.json 시트와 같은 모양
  (`name, short, group:"수수료 원장", asofl, view[블록], cols/rows 빈 배열`). 앱 dash.js `addExtra` 가 '실적·KPI' 묶음 바로 뒤에 끼운다.
- 앱메모 형식(2026-11-18 추가): `recon` = {신고기간: {st, nt, bs, rk, ru, re, dk, du, de}}(대사 상태·대사 기준·원화/외화 차이), `xcheck` = {sched[], cmx[], hix[], hist{}, inv[], dup[], plan[], other[]}(크로스체크 쪽). 둘 다 기관명·금액이 들어가므로 Project 문서에만 둔다. 없으면 예전 화면 그대로.
- 원장 CSV 선택 열(2026-11-18 v2): `약정 연결`(표 id|운용사|약칭|기관, ' ; ' 여러 개 — 대시보드 엑셀 표기 그대로) · `약정 연결 방식`(기관 = 산정근거·펀드 이름의 기관명 / 금액 = 약정 합계로 / 펀드 전체 / 약정 없음) ·
  `약정 펀드`·`약정 LP`·`약정금액`·`수수료율·보수 조건`·`약정내역 수수료`·`약정 연결 메모`(--dash 없이 만들 때 쓰는 값). 연결은 '수수료 내역 증빙 자료' 대화에서 원장 행마다 정한다(기관명이 들어가 공개 코드에 규칙을 두지 않음).
- 약정내역 수수료 = 기관별 약정 × 그 해 수수료율(EUR 약정은 EUR — 시트의 USD 환산 칸이 아님, 율 없는 정액은 칸 값 그대로). 2010~2021 약정은 '보수 조건'·'잔여 보수' 글자.
- fees.json 에 `src`(원장 행·앱메모·CSV 이름)를 담아 `--from` 으로 다시 만들 수 있다 — 암호문으로만 저장소에.
- 점검용 가상 데이터: `tests/fees-fixture.json`(가상만, `fees_build.py` 출력 — 가상 원장 7건 + 가상 recon·xcheck·약정 연결) — smoke 맨 뒤 '수수료 원장' 점검 때만 내보낸다.
